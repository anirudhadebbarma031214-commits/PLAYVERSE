# PLAYVERSE

A responsive, dark-neon mini-game portal made with HTML, CSS and JavaScript.

## Included
- Search and category filters
- Favorites saved in browser localStorage
- 12 playable mini-games: Neon Clicker, Memory Match, Snake Byte, Brain Blitz, Reflex Rush, Color Rush, Math Sprint, Target Tap, Rock Paper Scissors, Number Guess, Typing Dash and Coin Flip Duel
- Mobile-friendly responsive layout
- GitHub Pages deployment with GitHub Actions

## Publish
1. Open **Settings → Pages** in this repository.
2. Set the build/deployment source to **GitHub Actions**.
3. Push to `main` (or run the workflow manually from Actions).
4. Once the workflow succeeds, the site should be available at https://anirudhadebbarma031214-commits.github.io/PLAYVERSE/

No build step or external game API is required.
